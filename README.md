# Neportal - Telegram-first операционная система для небольших команд

**Neportal** - homegrown SaaS для задач, расходов, чеков, отсутствий и ежедневных операций через Telegram и веб-панель руководителя.

## AI как инструмент усиления человека

Ключевой принцип: **AI не заменяет человека и не принимает бизнес-решения самостоятельно**. Он помогает разобрать обычные сообщения и голосовые, извлечь смысл и превратить переписку в понятные действия.

> **AI помогает понять намерение. Человек сохраняет контроль. Код отвечает за надёжность.**

Пользователь пишет боту естественной фразой. AI помогает понять: кому задача, какой дедлайн, какой расход, к какой задаче комментарий. Система показывает preview, просит подтверждение и только затем сохраняет действие.

- AI ускоряет ввод, но не принимает важные решения;
- перед сохранением всегда есть preview;
- спорные случаи уходят на уточнение;
- код проверяет сотрудников, роли, права, organizationId, бюджеты, задачи и даты;
- простые команды - детерминированная логика без AI;
- сложные формулировки - через AI с последующей валидацией.

Примеры сообщений:

> «Поставь Васе задачу завтра проверить склад»  
> «Потратил 1500 на рекламу»  
> «Я заболел, больничный до пятницы»

## Prompt engineering

Промпты переводят человеческую речь в структурированные данные для проверки, а не управляют бизнесом. AI распознаёт намерение, выделяет исполнителя, дедлайн, сумму, бюджет, отделяет название задачи от описания, возвращает JSON и сигнализирует о неуверенности.

AI-слой работает вместе с deterministic parsers и бизнес-логикой: «мои задачи» - без модели; preview действий - с inline-кнопками (Подтвердить / Изменить / Отменить), при этом «да», «нет» и выбор по номеру по-прежнему работают; сложный текст, длинные сообщения и голос - через AI.

Подробнее: [AI intent](docs/ai-intent.md), [Telegram-бот](docs/bot.md).

## Продукт в двух словах

Neportal снимает операционный хаос из переписок: задачи, дедлайны, расходы, чеки, бюджеты, больничные, перераспределение работы. Сотрудники остаются в Telegram; руководитель получает структурированную веб-панель.

Целевая аудитория - небольшие команды (агентства, сервис, стройка, торговля, полевые сотрудники), где процессы уже живут в мессенджере и не нужна тяжёлая ERP.

Продукт развивается как homegrown-инструмент: итерации на реальных сценариях, вайбкодинг для быстрой проверки гипотез, строгая логика там, где AI не нужен.

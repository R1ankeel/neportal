# Neportal

**Neportal** — внутренний цифровой портал компании: проекты, задачи, заметки, бюджеты и расходы, сотрудники, больничные и отпуска. Всё собрано в одном месте вместо разрозненных чатов и таблиц.

## Для кого

| Кто | Как пользуется |
|-----|----------------|
| Руководители и менеджеры | Веб-сайт: проекты, задачи, сотрудники, бюджеты, отсутствия |
| Сотрудники в работе | Telegram-бот: поставить задачу, записать расход, отметить больничный или отпуск |
| Бухгалтерия и учёт | Бюджеты по проектам, расходы с чеками, контроль неподтверждённых трат |

## Что даёт организации

- **Задачи** — кто что делает, сроки, статусы, комментарии и передача между людьми; уведомления в Telegram.
- **Заметки** — быстрые записи по проекту (в том числе голосом из мессенджера в перспективе).
- **Бюджеты и расходы** — лимиты по направлениям, траты с подтверждением чеком, если это требуется правилами бюджета.
- **Отсутствия** — больничные и отпуска с учётом затронутых задач и уведомлением коллег.
- **Сотрудники** — список команды, привязка Telegram к учётной записи в портале.

## Как этим пользуются

**Веб-интерфейс** — для обзора: проекты, карточки задач, настройка бюджетов, добавление сотрудников и их Telegram-username для привязки бота.

**Telegram-бот** — для повседневных действий: команды вроде `/task`, `/expense`, `/sick` или обычные фразы («поставь Васе задачу…», «потратил 1500 на рекламу»). Бот показывает, что понял, и просит подтвердить «да» или «нет», прежде чем сохранить данные в портале.

Оба канала работают с **одной базой данных**: то, что создано в боте, видно на сайте, и наоборот.

## Статус проекта

Сейчас это **внутренний MVP** (минимально жизнеспособная версия) для разработки и пилота:

- рассчитан на **одну организацию** в демо-режиме;
- **нет входа по логину и паролю** на сайте — это не готовый продукт для внешних клиентов;
- репозиторий **приватный**, только для внутреннего использования.
